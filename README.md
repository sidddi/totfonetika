# TotFonetika

Transcriptor fonètic del català (AFI): central, valencià, nord-occidental, balear, rossellonès i alguerès. Eina orientativa: pot contenir errors.

Àudio: botó «Escolta» amb la veu catalana local del dispositiu (llegeix el text, no la transcripció; només apareix si la veu és local, per privacitat).

Indexació: la web porta `noindex` mentre no hi hagi domini propi. Per obrir-la a Google: meta robots -> `index, follow`, actualitza `canonical`, `og:url`, el JSON-LD i `sitemap.xml` al domini nou, i enllaça el sitemap des de `robots.txt`.

Pronúncies: Wiktionary i Viccionari (CC BY-SA 4.0), vegeu lexicon.json i ATTRIBUTION.md.

Web: https://sidddi.github.io/totfonetika/

Eines i proves (no es publiquen amb el web): branca `claude/catalan-wiktionary-pronunciations-wbwlrf`, carpeta `tools/`
(`bash tools/tests/run.sh` abans de fusionar a `main`).
