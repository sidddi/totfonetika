# TotFonetika

Transcriptor fonètic del català (AFI): central, valencià, nord-occidental i balear. Eina orientativa: pot contenir errors.

Pronúncies: Wiktionary i Viccionari (CC BY-SA 4.0), vegeu lexicon.json i ATTRIBUTION.md.

Web: https://sidddi.github.io/totfonetika/

Eines i proves (no es publiquen amb el web): branca `claude/catalan-wiktionary-pronunciations-wbwlrf`, carpeta `tools/`
(`bash tools/tests/run.sh` abans de fusionar a `main`).
